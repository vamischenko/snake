# Змейка

Классическая игра «Змейка» в браузере: таблица HTML, логика на чистом JavaScript, стили в CSS. Без сборки и зависимостей.

## Как запустить

Откройте `index.html` в браузере (двойной клик или через локальный сервер).

Через встроенный HTTP-сервер Python:

```bash
cd /path/to/snake
python3 -m http.server 8080
```

Затем в браузере: `http://localhost:8080`.

## Управление

- **Старт** — начать игру (поле очищается, счёт сбрасывается).
- **Новая игра** — остановить таймер и очистить поле без перезагрузки страницы.
- **Стрелки** — направление движения (нельзя развернуться на 180° за один шаг).

Поле **тороидальное**: выход за край переносит змейку на противоположную сторону.

## Правила

- **Зелёная клетка** — еда: змейка растёт, на поле появляются новая еда и красный «мангуст» (опасная клетка).
- **Красная клетка** — проигрыш при наступлении.
- **Столкновение с собой** — проигрыш.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `index.html` | Разметка и подключение скриптов |
| `js/snake.js` | Игровая логика |
| `css/style.css` | Оформление |

## Технические детали

- Размер поля: 20×20 клеток, шаг таймера 300 мс (константы в начале `snake.js`).
- Инициализация после `DOMContentLoaded`, скрипт подключается с атрибутом `defer`.

## Лицензия

Пет-проект; используйте код свободно.
